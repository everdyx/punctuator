# Punctuator

Punctuator 是一个 macOS 菜单栏小工具，用来解决中英文混合输入时的标点切换问题。

当光标前一个字符是中文标点时，轻按一次设置的触发键（默认右侧 `Shift`），Punctuator 会把它替换成对应的英文半角标点。例如：

```text
你好。 -> 你好.
你好， -> 你好,
路径、文件 -> 路径\文件
```

## 功能

- 可选择右侧 `Shift`、`Option` 或 `Control` 触发转换
- 所选触发键自身会被拦截，不再执行原本的修饰键功能
- 只处理所选触发键的 modifier 事件，不改写其它键盘按键
- 设置窗口支持添加、删除、编辑符号对应关系，以及恢复默认
- 设置保存在本机，保存后立即生效，重启后保留
- 支持菜单栏启用/停用
- 支持显示权限状态和上一次转换结果
- 转换后尽量把光标放回原替换位置之后，适合在句中修改

## 支持的标点映射

```text
。 -> .
， -> ,
、 -> \
？ -> ?
！ -> !
： -> :
； -> ;
（ -> (
） -> )
【 -> [
】 -> ]
《 -> <
》 -> >
“ ” -> "
‘ ’ -> '
```

## 安装和使用

1. 下载或构建 `Punctuator.app`
2. 打开 app，菜单栏会出现 `P.` 或 `P?`
3. 在 macOS 系统设置中授予权限：
   - 隐私与安全性 -> 辅助功能
   - 隐私与安全性 -> 输入监控
4. 授权后退出并重新打开 Punctuator
5. 在任意文本输入处输入中文标点，例如：

   ```text
   你好。
   ```

6. 光标停在 `。` 后面，轻按右侧 `Shift`
7. 文本会变成：

   ```text
   你好.
   ```

菜单栏状态说明：

- `P.`：已启用，权限正常
- `P?`：权限或事件监听还没有准备好
- `P-`：已停用

菜单里的 `Last Action` 会显示上一次读取和替换的结果，方便排查问题。

## 设置

点击菜单栏 Punctuator 图标，选择 **设置…**。

- **触发按键**：可选右侧 Shift、右侧 Option、右侧 Control。默认仍为右侧 Shift。
- **符号对应关系**：每行填写一个原字符和对应替换内容；替换内容可以包含多个字符。可添加或删除规则。
- 原字符不可重复，替换内容不能为空，规则不可包含换行。全部删除规则则不再转换任何符号。
- 点击 **保存** 立即生效；**取消** 或关闭窗口会放弃未保存的修改。
- **恢复默认** 会重置窗口中的按键和规则，点击保存后才正式生效。

例如选择右侧 Option，并将 `。` 对应内容改为 `...`，保存后在 `你好。` 后轻按右侧 Option，将得到 `你好...`。未被选作触发键的按键保留系统原有行为。

## 权限说明

Punctuator 需要两个 macOS 权限：

- **辅助功能**：用于读取当前文本选区，并把中文标点替换成英文标点
- **输入监控**：用于监听并拦截右侧 `Shift`

如果你已经授权但菜单栏仍显示 `P?`，可以尝试：

1. 退出 Punctuator
2. 在辅助功能和输入监控里删除旧的 Punctuator 项
3. 重新打开当前版本的 `Punctuator.app`
4. 把当前这个 app 重新加回两个权限列表
5. 再次退出并打开 Punctuator

开发阶段如果频繁重新构建、重新签名，macOS 可能会把新版本当作另一个 app，因此需要重新授权。

## 构建

需要：

- macOS 13 或更高版本
- Xcode / Command Line Tools
- Swift 5.9 或更高版本

构建命令：

```bash
cd /path/to/punctuator
bash scripts/build_app.sh
```

构建产物会输出到：

```text
Release/Punctuator.app
```

如果你是在仓库根目录使用，可以根据自己的目录结构调整输出路径。

## 技术实现

Punctuator 使用 Swift + AppKit 实现。

核心流程：

1. 使用 `CGEventTap` 在 HID event tap 层监听所选触发键
2. 拦截所选触发键的 modifier 事件，并在松开时触发
3. 触发后模拟 `Shift + Left` 选中光标左侧一个字符
4. 优先通过 Accessibility API 读取选中文本
5. 命中映射后，通过 Accessibility API 替换文本并恢复光标位置
6. 必要时回退到复制/粘贴方式

## 已知限制

- 某些 App、网页输入框、终端、远程桌面、密码框或安全输入区域可能不允许读取或修改文本
- macOS 权限系统可能缓存旧版本 app 的授权状态
- 当前版本支持触发键和符号规则设置，暂不支持黑名单 App
